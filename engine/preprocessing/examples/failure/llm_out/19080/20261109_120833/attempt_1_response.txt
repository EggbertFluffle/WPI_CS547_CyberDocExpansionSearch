The exploit leverages a suidmanager vulnerability (CVE-1999-1390) where a malicious suid root shell script on the system allows arbitrary command execution as root. It uses the /usr/bin/suidexec binary to run a specified program with elevated privileges, exploiting the lack of proper permission checks for suid scripts. This mechanism enables an attacker to execute commands with the same privileges as the affected process.

The weakness is that suid root shell scripts are executed without verifying their permissions or ownership, allowing any user to trigger arbitrary command execution. The exploit allows an attacker to run commands with the privileges of the script's owner, effectively gaining full administrative control over the system.
